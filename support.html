Frequently asked questions

Where are my files stored?

Wherever you keep them. The app opens the file you pick, edits it in place, and keeps no copy of its own beyond a working file that protects you against losing work mid-edit. Nothing is uploaded — the app has no network access at all.

Does it work offline?

Always, because there is no online. Every feature — scanning, text recognition, editing, redaction, compression — runs on your device.

I scanned a page but Edit Text says there is nothing to edit.

A photographed page is a picture: the words are pixels, not text. Use Recognize to add an invisible text layer so the page becomes searchable, or Make Text Editable in Edit Text to read the lines and retype one in place. Replacing a line covers the original pixels for good, and the replacement is set in a standard font, so it will not match the scan exactly.

Can I copy text out of a scan?

Yes. In Edit Text choose Make Text Editable, then press and hold on a word and drag the handles across lines — or use Select All — and Copy or Share. Nothing is written to the file by selecting.

Compress did not make my file smaller.

Compression re-encodes images that are stored at far more detail than they are drawn at, and touches nothing else — text and vector drawings are never rasterised, so the document stays searchable and sharp. A file with no oversized images has nothing to gain, and the app says so rather than pretending. It never returns a larger file than you gave it.

Is redaction really permanent?

The tool removes the page objects that intersect what you marked and then draws the black box — it does not merely cover the content. The file is saved as a full rewrite, so the removed content is not recoverable from it. Anything overlapping a mark is removed whole, so slightly more may go than you outlined. Always check the result before sharing it.

Can I export to Word?

Yes. Choose Export and pick Word, or use Export Text in Recognize. The pages are read first, then the words are written out in reading order, with headings and page breaks kept.

Be clear on what that is: it exports the text, not the layout. Columns, tables and the original fonts are not reproduced, because nothing offline can recover them from a picture of a page without inventing most of it. What you get is every word in an editable Word file instead of locked inside an image — which is what people usually want when they ask. It takes a moment, because reading the pages is real work.

What about Excel?

No. A spreadsheet is a grid of typed cells, and reconstructing that from a scan means guessing at the grid and at which values are numbers. A wrong number in a spreadsheet is worse than no spreadsheet.

Why does my signature not appear on my other device?

By design. Signatures are held in a file inside the app's own storage on the device that created them, excluded from backups, and never synced. A signature is the one thing that should never travel.

Something went wrong with a document.

Your original is not overwritten until you choose Save, and every change is written to a draft moments after you stop, so a crash loses nothing. If a document comes out wrong, keep the original and email me — with the file if you are able to share it, and without it if you are not.
